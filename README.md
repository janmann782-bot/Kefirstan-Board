# KefirBoard

Офлайн-клавиатура для Android, разработанная под индивидуальное ТЗ. Системный IME на Kotlin, без рекламы, аналитики и разрешения `INTERNET`.

## Версия 0.2.0: дизайн и химический режим

- Переработанный экран настроек и предпросмотра в графитово-зеленом дизайне по UI-концепту KefirBoard: карточки Aurelia Wiki, математики и химии; светлая/темная темы и увеличенный предпросмотр клавиатуры.
- Отдельная вкладка «⚗ Химия» в системной клавиатуре: элементы, формулы (включая нижние индексы), верхние индексы зарядов, стрелки реакций, быстрые примеры, копирование результата в поле ввода.
- Реальное офлайн-уравнивание **обычных молекулярных реакций** с целочисленными коэффициентами, используя точные дроби и проверку сохранения числа атомов. Например `H2 + O2 -> H2O` превращается в `2H₂ + O₂ → 2H₂O`.
- Тесты для воды, оксида железа, гидроксида кальция, некорректных формул и повтора уже расставленных коэффициентов.
- Поддержка ионного электронного баланса, степени окисления, органических структурных формул и предсказания продуктов реакции **не реализована**. Символы зарядов можно вставлять как текст, но химический балансер не учитывает заряд.
- Изображение UI sprite sheet служит визуальным ориентиром. Клавиши и карточки реализованы **нативными Android View**, а не нечеткими растровыми фонами, поэтому элементы реагируют на нажатия и масштабируются.
- По-прежнему нет разрешения `INTERNET`. Архив вики Аурелии уже встроен в assets.

## Что уже есть в первом прототипе

- Реальная клавиатура Android (`InputMethodService`), русская ЙЦУКЕН и английская QWERTY, цифровой ряд, постоянные точка и запятая
- Темная графитовая и светлая темы, зеленый акцент `#A9F38F`, обводки, настройки высоты и расстояний
- Переключение языка свайпом по пробелу, удержание пробела для перемещения курсора, удаление слова свайпом по Backspace
- Режимы букв, математического ввода, поиска по вики и буфера обмена
- Шифрованное хранилище истории буфера через Android Keystore + SQLite, без лимита количества записей (ограничение: память устройства)
- Реальная офлайн-база из 740 страниц выгрузки `Aurelia_Wiki_updated.xml` (MediaWiki), автоматическая индексация при первом запуске и поиск
- Калькулятор для арифметических выражений и линейных уравнений с объяснением преобразований, все локально

## Что пока НЕ реализовано

Полноценный свайповый ввод слов, обучающиеся предиктивные модели, голосовой ввод, переводчик с языковыми моделями, поддержка изображений и GIF в буфере, PIN/биометрия, редактор перестановки клавиш, полноэкранный математический интерфейс, графики, производные и интегралы, сложные системы уравнений, экспорт/импорт данных. Это **дальнейшие этапы**, а не готовые функции.

## Сборка

Открой проект в Android Studio с JDK 17 и установленным Android SDK 35 или используй Gradle 8.9:

```bash
gradle :app:assembleDebug
```

APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`.
Также workflow **Android Debug APK** на вкладке GitHub Actions после успешного запуска прикладывает APK артефактом.

## Установка и включение

1. Установить debug APK на Android 8.0+.
2. Открыть KefirBoard, выбрать «Включить KefirBoard в настройках Android».
3. Затем нажать «Выбрать KefirBoard для ввода».
4. При первом использовании вики будет проиндексирована в локальную SQLite-базу в фоне.

## Приватность

В манифесте намеренно нет `android.permission.INTERNET`. Клипы шифруются по отдельности AES-GCM с ключом Android Keystore. Не записываем содержимое защищенных полей ввода. Запись системного буфера возможна только тогда, когда Android разрешает доступ (во время работы активной клавиатуры). История без фиксированного лимита, но не без ограничения памяти. В прототипе еще нет пользовательского экрана разблокировки защищенного буфера, поэтому аппаратная защита ключей **не означает**, что каждый просмотр требует биометрии.

## Источник вики

`app/src/main/assets/aurelia_wiki.xml` — локальная выгрузка из пользовательской библиотеки, 740 страниц. Приложение не обращается к Fandom. Лицензию и права на распространение выгрузки следует проверить перед публичной публикацией.

## Статус

Первый рабочий исходный проект. GitHub Actions должен собрать debug APK. Если CI сообщает об ошибках, они подлежат исправлению до того, как сборка может считаться подтвержденной.
